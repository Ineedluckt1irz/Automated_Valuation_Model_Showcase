# Automated Financial Valuation & 3-Statement Modeling Engine

本專案為一套基於 Python 開發的全自動化財務建模與估值系統。透過串接 Yahoo Finance API 獲取上市企業財務數據，系統能自動建構具備完整會計勾稽關係的預測性財務三表，並同步產出包含絕對估值 (DCF)、相對估值 (Multiples) 與分類加總估值 (SOTP) 的機構級 Excel 財務模型。

## 核心工程與財務處理邏輯

本系統不僅處理數據爬蟲，更著重於資料的財務邏輯正確性與自動化報表交付標準：

### 1. 財務三表連動與會計勾稽 (3-Statement Linkage)
* **嚴謹的會計基礎:** 系統內建完整的資產負債表 (BS) 滾動邏輯，包含保留盈餘 (Retained Earnings) 的淨利與股息調節、固定資產 (PPE) 的資本支出與折舊攤銷調節，確保三大表完全平衡，並自帶資產負債檢核機制 (Check: A - L - E = 0)。
* **營運資金動態預測 (Working Capital):** 透過歷史應收帳款天數 (DSO)、存貨天數 (DSI) 與應付帳款天數 (DPO) 驅動未來的現金流預測，精準反映真實的商業營運週期與資金占用成本。

### 2. 四大相對估值矩陣 (Multiples Valuation)
* **歷史軌道運算:** 針對 P/E、P/S、P/B 與 EV/EBITDA，系統利用歷史每日收盤價與插值法 (Interpolation) 計算滾動乘數，並透過百分位數 (15%, 35%, 50%, 65%, 85%) 嚴謹劃分歷史估值區間。
* **自動化河流圖:** 輸出的 Excel 內建原生折線圖表 (LineChart)。透過直接將 Excel 函數 (而非靜態數值) 寫入儲存格，當使用者在試算表中手動微調合理倍數時，河流圖與目標價矩陣將自動重新計算並變形。

### 3. 多階段自由現金流折現模型 (DCF Engine)
* **五大動態模型:** 支援一階段、二階段、三階段，以及考量成長率平滑遞減的 H-Model (二階段/三階段 H模型)，以應對不同生命週期的企業型態。
* **動態 WACC 計算:** 系統自動抓取 Beta 值與無風險利率，並依據即時市值與有息負債 (Interest-bearing Debt) 計算資本結構權重，確保折現率符合當下市場風險溢酬。

### 4. 業務分類加總估值 (SOTP Module)
* 針對多角化經營之控股集團，系統提供由下而上 (Bottom-Up) 的 SOTP 模組。可獨立設定各事業體的營收成長率、淨利率與目標乘數，並在考量控股公司折價 (Holding Company Discount) 後推算企業整體合理股價。

## 技術棧與系統架構

* **資料獲取與運算:** `yfinance`, `pandas`, `numpy`
* **報表渲染與公式封裝:** `openpyxl` (精準控制儲存格格式、色彩編碼、Excel 原生函數寫入與圖表生成)
* **防呆與容錯機制:** 內建 Excel 檔案佔用偵測，若遇權限衝突 (PermissionError) 會自動以時間戳記另存新檔，確保批次運算不中斷。

## 系統執行流程

執行主程式後，系統將提供終端機互動介面：
1. 輸入目標公司代碼 (如: AAPL, 2330.TW)。
2. 配置 DCF 參數：選擇估值模型 (1-5) 並輸入預期成長率。
3. 配置 SOTP 參數：決定是否啟用分類加總模組並設定事業群數量。
4. 交付產出：系統將自動生成 `[Ticker]_Master_Model.xlsx` 於本地目錄。
